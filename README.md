This is a tutorial for WGCNA. The file is an R Markdown document that allows you to test the code and view the output yourself.
For more control over the exported files, you can modify the code as needed.

The analysis is performed using random data. If the dataset is too large for your system to handle, try reducing the number of genes or removing a few samples from each cell type.
There is much more that can be done using the WGCNA package; however, this tutorial includes only the most practical steps.
Downstream analyses—such as network analysis and visualization, Gene Ontology, and others—need to be performed separately.
